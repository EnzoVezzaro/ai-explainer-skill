Architecture

System architecture

Website → CLI installer → Agent Skill → Existing AI coding harness → Verified result
  • Website — discovery, onboarding, docs, examples, bounded playground. Decoupled from the skill runtime.
  • CLI — npm-distributed toolkit for install, configure, maintain, learn, create, validate.
  • Core Agent Skill — video-skill with Learn / Explain / Create / Build / Verify / Improve.
  • Existing harness — does reasoning, code editing, shell execution, and workspace operations with user permissions.

Repository layout

video-skill/
├── apps/web/          # landing, docs, playground, examples
├── packages/
│   ├── cli/           # npm CLI
│   ├── core/          # shared contracts
│   ├── agent-reach-adapter/  # video retrieval integration
│   ├── video-analyzer/       # evidence extraction
│   ├── skill-compiler/       # Agent Skill generation
│   ├── skill-evaluator/      # validation & evaluation
│   └── installers/           # harness-specific install adapters
├── skills/video-skill/  # portable core skill
└── tests/               # unit + e2e tests

Design principles

  • One installable skill system, one CLI, one website, multiple coding agents.
  • Core skill stays portable; provider-specific differences live in installers.
  • Website is decoupled from the skill runtime.
  • No hosted database or product API required for basic CLI/Skill operation.
  • Playground server-side jobs are bounded, isolated, and abuse-controlled.
  • All external video content is untrusted.
