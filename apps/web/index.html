// How it worksURL → evidence → skill → agent

From a video link to files your agent can read.

This site writes files. Your coding harness decides what to run. Extraction uses the video's public description, captions and transcript, and each step keeps its source label.

01 / Learn

Read the source

Public YouTube, Bilibili, Instagram, X, TikTok and web page URLs all work. Captions, Whisper transcripts when configured, chapters, links and tools become structured evidence.

02 / Explain

Keep the sources separate

Spoken instructions stay separate from visible demos, linked docs and guesses. Missing captions are reported as gaps.

03 / Create

Write the skill folder

The output is a folder with SKILL.md and references for tools, walkthrough, source evidence and dependencies: references/tools.md, walkthrough.md, source.md and dependencies.md.

04 / Verify

Hand it to your harness

Install the skill and run the workflow with your approval. Tests, logs and screenshots count as evidence. Prepared skills stay marked as prepared.

External content is untrusted. Actions that change files or spend money need your approval. Video Skill does not claim a reproduction it never ran.

// What ships with itCLI + MCP + Agent Skill

The same pipeline, in three places.

The CLI runs on its own with npx. The MCP server at http://localhost:3002/mcp exposes the same steps as tools, so another agent can start a run and watch it.

MCP tools

  • extract: structured evidence from a URL
  • compile: build a portable skill
  • validate: check the generated skill
  • list_collections: saved sources
  • run_workflow: start a tracked build
  • workflow_status: steps and agent thread
  • list_workflows: previous runs

CLI commands

  • video-skill learn <url>
  • video-skill create <url> --out <dir>
  • video-skill validate <dir>
  • video-skill install / update / uninstall
  • video-skill doctor / providers
