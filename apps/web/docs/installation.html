Installation

Install Video Skill

Install the CLI once, then install the core video-skill Agent Skill into your coding harness.

Step 1 — Install the CLI 
npx video-skill install

This installs the video-skill npm package and runs the harness detector.

Step 2 — Choose project or global scope

The installer detects your coding harnesses and offers project-level or user-level installation where the provider allows it.

# Project-scoped (recommended, committed with the repo)
npx video-skill install --scope project

# User-scoped (available across your projects)
npx video-skill install --scope user

# Target a specific harness
npx video-skill install --provider claude-code --scope project
Step 3 — Reload your coding agent

Reload Codex, Claude Code, OpenCode, or Cursor so it discovers the installed skill.

Uninstall / update

npx video-skill update      # refresh an existing install
npx video-skill uninstall     # remove only installer-managed video-skill targets

Install, update, and uninstall are safe and reversible. The installer never overwrites existing files without confirmation (--force to override).

Detected providers

Run npx video-skill providers to see which coding agents are detected on your machine and where skills would be installed.

No hosted database, proprietary account, or product API is required for basic CLI or Skill operation. Video retrieval uses Agent Reach where configured.
