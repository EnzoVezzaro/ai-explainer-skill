Overview

Documentation

Video Skill helps existing AI coding agents learn actionable workflows from instructional videos and turn them into reusable, executable Agent Skills.

Architecture:

Website → CLI installer → Agent Skill → Existing AI coding harness → Verified result
  • Website — discovery, onboarding, docs, examples, bounded playground.
  • CLI — npx video-skill install and related commands.
  • Core Agent Skill — video-skill, teaches agents how to learn from videos.
  • Existing harness — Codex, Claude Code, OpenCode, Cursor (where compatible), etc.
Not a new coding agent. Video Skill does not build a chat platform, coding harness, desktop app, or orchestration framework. It augments the harness you already use.

Quick start

# 1. Install into your project or globally
npx video-skill install

# 2. Learn from a public tutorial video
npx video-skill learn https://www.youtube.com/watch?v=EXAMPLE

# 3. Create a portable Agent Skill from the tutorial
npx video-skill create https://www.youtube.com/watch?v=EXAMPLE --out ./generated

# 4. Validate the generated skill
npx video-skill validate ./generated/

# 5. Install into a coding harness and execute with authorization
npx video-skill install --provider claude-code --scope project

Then open your coding agent and ask it to follow the generated skill in your workspace. Build prepares a skill; execution happens only with your authorization.
