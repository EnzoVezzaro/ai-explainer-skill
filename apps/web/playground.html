Interactive playground

Extract, create, build

Paste a public instructional video URL. Choose what you want to do. This prepares artifacts — execution happens in your coding harness with your authorization.

YouTube and Bilibili are supported via Agent Reach; other public URLs use a generic read fallback.


  


  

    Build ≠ Execute. The Build action prepares an executable skill and execution plan. The actual tutorial workflow runs in your selected coding harness (Codex, Claude Code, OpenCode, Cursor) only after you install the skill and authorize consequential operations. This playground does not execute code on your behalf and never stores coding-agent credentials.
  


  

    
What you get

    
    
      
  • Explain — a clear technical walkthrough of the tutorial, with evidence labeled as spoken / visible / description / external-doc / inference.
    • 
      
  • Create Skill — a downloadable Agent Skill folder (SKILL.md + references/) you can install into your coding agent.
    • 
      
  • Build — the generated skill plus an execution plan and a copyable command for your coding harness.
