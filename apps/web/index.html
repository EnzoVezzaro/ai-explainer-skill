How it works

Website → CLI → Agent Skill → Your coding agent → Verified result

Four steps. The website never executes code for you — your harness does, with your authorization.

1 Learn

Paste a public tutorial URL. Video Skill retrieves metadata, transcript/captions, chapters, links, tools, and demonstrated actions.

2 Explain

Get a clear technical walkthrough that separates spoken instructions from visible demos, external docs, and inference.

3 Create

Compile the tutorial into a portable Agent Skill (SKILL.md + references) using Skill Creator conventions.

4 Build / Verify

Hand the skill to your harness for execution with your approval, then confirm with real tests, logs, or screenshots.

Interactive playground

Generate a skill without installing

Paste a public tutorial video URL and run Explain, Create Skill, or Build. The preview shows extraction status, the generated skill outline, references, and an execution plan.

Open the playground See CLI commands
Bounded by design. The playground never asks for your coding-agent credentials and is not a cloud IDE. Build prepares a skill; it does not execute it.
