// The pipelineURL → evidence → skill → agent

One URL in. A built skill out.

The website prepares a skill; it never executes a tutorial for you. Extraction is grounded in the video's public description, captions and transcript, and every claim is labeled by source.

01 / LEARN

Retrieve

Read a public YouTube, Bilibili, Instagram, X / Twitter, TikTok or web page URL. Captions or Whisper transcripts, chapters, links and tools become structured evidence.

02 / EXPLAIN

Understand

Separate spoken instructions from visible demos, external docs and inference. Nothing is presented as verified when it was only guessed.

03 / CREATE

Compile

Generate a portable skill: SKILL.md, references/tools.md, walkthrough.md, source.md and dependencies.md.

04 / VERIFY

Hand off

Install into your harness and run the workflow with your approval. Confirm the result with real tests, logs or screenshots — never a simulated success.

External content is untrusted. Consequential actions require explicit authorization, and the tool never claims a reproduction it did not execute.

// Under the hoodCLI + MCP + Agent Skill

Built for the agent you already use.

The CLI works standalone via npx. The same pipeline is exposed over MCP at http://localhost:3002/mcp, so your coding agent can drive a tracked workflow instead of improvising one.

Seven MCP tools

  • extract — structured evidence from a URL
  • compile — build a portable skill
  • validate — check the generated skill
  • list_collections — saved sources
  • run_workflow — start a tracked build
  • workflow_status — steps and agent thread
  • list_workflows — previous runs

CLI commands

  • video-skill learn <url>
  • video-skill create <url> --out <dir>
  • video-skill validate <dir>
  • video-skill install / update / uninstall
  • video-skill doctor / providers
