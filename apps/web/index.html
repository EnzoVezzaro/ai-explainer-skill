How it works

Website → CLI → Agent Skill → Your coding agent → Verified result

1. Learn

Paste a public tutorial video URL. Video Skill retrieves metadata, transcript/captions, chapters, links, tools, and demonstrated actions.

2. Explain

Turns the video into a clear technical walkthrough, separating spoken instructions from visible demos, external docs, and inference.

3. Create

Compiles the tutorial into a portable Agent Skill (SKILL.md + references) using Skill Creator conventions.

4. Build / Verify

Hands the skill to Codex, Claude Code, OpenCode, or Cursor for execution with your authorization, then confirms real results.

Supported coding agents

Installs into your harness natively

Codex CLI Claude Code OpenCode Cursor (compatible) More via adapters

Uses each harness's native skill directory and metadata. Project-level and user-level installs where the provider allows them. No unified slash-command mechanism is invented.

Interactive playground

Generate a skill without installing

Paste a public tutorial video URL and run Explain, Create Skill, or Build. The preview shows extraction status, the generated skill, references, and an execution plan.

Open the playground

The playground runs bounded, isolated analysis jobs. It never asks for your coding-agent credentials and is not a cloud IDE. Build prepares a skill; it does not execute it.
