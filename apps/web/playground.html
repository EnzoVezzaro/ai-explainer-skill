Build ≠ Execute. The Build action prepares an executable skill and execution plan. The actual tutorial workflow runs in your selected coding harness (Codex, Claude Code, OpenCode, Cursor) only after you install the skill and authorize consequential operations. This playground does not execute code on your behalf and never stores coding-agent credentials.


  
What you get

  

    
Explain
A clear technical walkthrough of the tutorial, with evidence labeled as spoken / visible / description / external-doc / inference.

    
Create Skill
A downloadable Agent Skill folder (SKILL.md + references/) you can install into your coding agent.

    
Build
The generated skill plus an execution plan and a copyable command for your coding harness.

    
Verify
Run video-skill validate and real tests in-harness. Only observed passes count — never simulations.
