MCP Server Connection

Connect your AI coding agent to Video Skill via the Model Context Protocol.

http://localhost:3002/mcp

Available Resources

  • video-skill://collections/{id} — Collection data
  • video-skill://collections/{id}/items/{itemId} — Item details
  • video-skill://collections/{id}/items/{itemId}/skill — Generated SKILL.md

Available Tools

  • extract — Extract content from a public URL
  • compile — Compile extraction into Agent Skill
  • validate — Validate a generated skill
  • list_collections — List all collections

Example: Claude Code MCP Config

{
  "mcpServers": {
    "video-skill": {
      "command": "npx",
      "args": ["video-skill-mcp", "--endpoint", "http://localhost:3002/mcp"]
    }
  }
}
