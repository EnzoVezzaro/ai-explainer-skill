Security & privacy

Security model

Every external video, description, transcript, caption, and generated instruction is treated as untrusted input.

  • No credential storage. The website never stores or handles your API keys or coding-agent credentials.
  • No DRM/platform bypass. Video Skill does not bypass provider authentication, platform protections, or DRM.
  • SSRF-safe retrieval. Hosted retrieval uses restrictive URL validation and private/local-network host blocking.
  • Prompt-injection resistance. Generated instructions are never treated as trusted execution authority.
  • Explicit authorization. Destructive or privileged operations require explicit approval before running.
  • Evidence without secrets. Execution logs preserve evidence while redacting secrets.
  • Safe archives. Generated skill archives cannot write outside intended directories when extracted.
Evidence labeling

Every extracted instruction is labeled by source type: spoken, visible, description, external-doc, or inference, with timestamps and source references where available. Nothing is fabricated.

Verification honesty

A tutorial is never reported as reproduced unless real commands, tests, logs, or screenshots were observed in the current environment. Simulations are never presented as verified executions.
