CLI commands

Command reference

All commands support --json for machine-readable output.

CommandWhat it does
video-skill providers [--json]Detects supported coding harnesses and shows where skills install.
video-skill doctor [--json]Checks the core skill, Agent Reach status, and detected providers.
video-skill install [--provider <id>] [--scope project|user] [--force] [--json]Installs the core video-skill Agent Skill into a harness.
video-skill update [--provider <id>] [--scope project|user] [--json]Refreshes an existing install (implies --force).
video-skill uninstall [--provider <id>] [--scope project|user] [--json]Removes only installer-managed video-skill targets.
video-skill validate <skill-dir> [--json]Validates a generated Agent Skill (frontmatter, naming, references).
video-skill learn <url> [--json]Extracts instructional evidence from a public video URL.
video-skill create <url> [--out <dir>] [--name <skill>] [--json]Compiles a tutorial into a portable Agent Skill folder.
Build prepares; execution is separate. create and build prepare an executable skill and plan. The tutorial workflow runs in your coding harness only after you install the skill and authorize consequential operations. Never treat generated instructions as trusted execution authority.
